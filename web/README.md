# ZKiss 모바일 웹

React + TypeScript + Vite, React Router, 일반 CSS로 구현한 프론트엔드 데모입니다. Pretendard Variable과 Manrope는 npm 패키지에서 자체 제공하므로 런타임 외부 폰트 요청이 없습니다. 백엔드·계약 호출은 하지 않습니다.

## 실행과 확인

저장소 루트에서 `npm ci` 후 `npm run dev`로 실행합니다. `/`는 행사 입장, `/preview`는 화면별 디자인 확인 목록입니다. `npm run build`는 타입 검사와 프로덕션 빌드, `npm run test:web`는 Playwright 흐름 테스트를 실행합니다. 첫 테스트 전 `npx playwright install chromium webkit`가 필요합니다.

## 동작

- 행사 입장 → 프로필 입력 → 사진 준비 → 분석 대기 → 프로필 미리보기 → AI 프로필 피드으로 이동합니다. 실제 입력 내용이 프로필 카드에 반영됩니다.
- 닉네임 1~12자, 나이 18~100, 성별, MBTI·SNS ID·20자 이내 자기소개와 사진 준비 상태가 필요합니다. 사진 버튼은 파일 선택 없이 준비 상태만 바꿉니다. 나이 범위는 데모 입력 검증이며 실제 행사 자격 인증이 아닙니다.
- 분석은 2.6초 후 예시 인상 카드로 연결됩니다. `/preview/analysis`만 디자인 확인을 위해 정지 상태를 유지합니다.
- 프로필 미리보기는 96px AI 예시 이미지와 4줄 인상 분석을 표시합니다. 이미지·문구는 고정 예시이며 실제 AI 생성은 하지 않습니다. 닉네임·나이·성별, MBTI, 직접 작성한 자기소개를 함께 표시하고 수정 링크로 상세 입력 단계에 돌아갑니다.
- 홈은 큰 AI 배경 이미지와 4줄 인상 분석의 카드 피드입니다. DM 버튼은 없으며 호감 전송 후 분홍색 완료 버튼과 연두색 알림을 표시합니다. 피드 필터는 전체·나에게 호감 보낸·나와 비슷한(나이 차이 1살 이내)입니다.
- 호감 화면은 받은 호감·보낸 호감 탭, 상대별 상태, 빈 상태, 피드 다시 보기로 구성합니다. 예시로 모카에게 받은 호감이 하나 있습니다. 라임에게 일방 전송하면 대기하고, 모카에게 답하면 상호 호감이 되어 대화가 열립니다.
- 대화방 접근은 상대별 받은/보낸 호감이 모두 있어야 가능합니다. 메시지·읽지 않은 개수·SNS 동의도 상대별로 분리됩니다. 받은 호감은 예시 데이터이며 실제 서버 수신이나 자격 검증은 연결하지 않았습니다.
- `/preview/matched`와 `/preview/room`에서 예시 매칭을 체험합니다. 입력한 메시지를 로컬 메시지 목록에 추가하고 공백 메시지는 차단합니다.
- SNS 요청은 본인 동의만 바꿉니다. 상대방 동의가 없으면 대기 상태로 남고 요청을 취소할 수 있습니다. 동의 없는 완료 URL 접근도 차단합니다.
- `/preview/shared`만 두 동의가 있는 예시 상태로 초기화합니다. 실제 SNS ID가 없으므로 ‘SNS 바로가기’는 데모 안내를 표시합니다. 임의의 실제 SNS 계정으로 이동하지 않습니다.

## 데이터 경계

모든 상태는 React 메모리에만 존재합니다. localStorage·sessionStorage·쿠키에 개인정보를 저장하지 않습니다. 새로고침하면 초기화됩니다. 사진 파일 선택·디코딩·업로드는 구현하지 않았습니다. 원본 사진·미리보기 URL·Base64를 상태에 저장하거나 전송하지 않습니다. 이것은 실제 AI 처리 후 서버 삭제를 구현하거나 검증한 것이 아닙니다.

프리뷰의 매칭·동의 fixture는 시각 검토용이며 보안 경계가 아닙니다. 제품화 시 인증된 서버/계약이 매칭·양쪽 SNS 동의를 검증하고, 승인 후에만 SNS 데이터를 클라이언트에 전달해야 합니다. 현재 프론트엔드에 실제 SNS 정보는 없습니다.

## 레이아웃과 에셋

디자인 기준 너비는 402px, 가로 여백은 20px입니다. 넓은 화면에서는 모바일 화면을 중앙에 표시하고 좁은 화면에서는 폭에 맞춰 줄어듭니다. Figma에 그려진 iOS 상태바(상단)와 Safari 툴바(하단)는 제외하고 실제 브라우저가 표시합니다. 하단 메뉴는 safe-area를 반영합니다. 채팅은 메시지 영역만 스크롤되고 입력창과 하단 메뉴는 유지됩니다.

`public/assets/`에는 Figma SVG·PNG 원본과 밝은 톤으로 별도 생성한 모카 예시 이미지가 있습니다. `assets.json`에 노드, 위치, 원본 크기를 기록했습니다. 프로필 이미지는 1254px 정사각형 원본을 96px로 표시하며, 사진 준비 배경은 CSS 그라디언트입니다. QR 영역은 원본 디자인처럼 흰 박스와 Z 표시이며 실제 스캔 가능한 QR을 생성하지 않습니다.

배포 시 SPA 경로를 `index.html`로 fallback하도록 호스팅을 설정해야 합니다.

## 연동 인계

미구현 기능, 백엔드·Midnight 공동 결정 사항과 연동 순서는 [FRONTEND_HANDOFF.md](../docs/FRONTEND_HANDOFF.md)를 참고하세요. 내 정보의 수정하기는 기존 입력 폼으로 연결하며 별도 수정 저장 API는 없습니다. 상호 호감 성사 팝업은 대화 시작/나중에 닫기를 지원합니다.
